## 우리가 만드는 것

| 분야 | 우리의 관심사 |
| :--- | :--- |
| 🛠️ **SaaS** | 반복되는 불편을 줄이고, 실제로 쓰고 싶은 서비스를 만듭니다. |
| 🎮 **Game Development** | 작은 프로토타입에서 시작해, 자꾸 생각나는 재미를 찾습니다. |
| 🔬 **Research** | 궁금한 건 직접 실험하고, 코드와 기록으로 남깁니다. |

## 함께 만드는 방식

**작게 시작하고, 직접 써보고, 같이 개선합니다.**

아이디어가 생기면 나누고, 돌아가는 첫 버전을 만듭니다. 서로의 코드를 리뷰하고, 플레이하고, 실험 결과를 비교합니다. 잘된 시도도 삽질도 다음 프로젝트의 재료가 됩니다.

완성한 결과물부터 진행 중인 실험까지, 이곳에 차곡차곡 쌓아갑니다.
